# Automatic College Timetable Generator

A Java-based desktop application developed as an Object-Oriented Programming (OOP) mini project to simplify college timetable generation.

## About the Project

The Automatic College Timetable Generator helps organize academic schedules by allocating theory lectures and practical sessions while considering faculty and batch constraints.

This project was developed by a team of three students from the Information Technology department of Shri Sant Gajanan Maharaj College of Engineering, Shegaon.

## Features

- Automatic timetable generation
- Theory lecture allocation
- Practical scheduling in consecutive periods
- Faculty and batch conflict checking
- Timetable preview
- Export timetable to a text file

## Technologies Used

- Java
- Java AWT
- Object-Oriented Programming (OOP)

## How to Run

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in Visual Studio Code.
4. Compile and run `src/app/Main.java`.
